# No permadeath in v1; failure is the Security Clock

Nobody dies permanently. A Runner at zero Physical boxes is Downed — out for the remainder of the Run, recovered at the Hub — and the run continues shorthanded. What ends a Run badly is the Security Clock: loud actions and failed tests tick it, and when it fills, security converges, the crew is forced to extract, and the payout is zero (or partial for early voluntary extraction), with Heat and Fixer reputation taking the loss.

**Considered options**: one death ends the Run (rejected: a single bad round deletes an hour of play); deaths permanent, run continues to the last Runner (rejected: balancing for party sizes one through four is a large amount of work for a loss state nobody enjoys); no failure state at all (rejected: fights stop mattering).

**Consequences**: this makes the game a roguelite, not a roguelike, and the Security Clock becomes the primary tension system — the whole design leans on it. It must therefore be tunable per Job type, visible at all times, and honest about what ticked it.
