# The Decker hacks the physical world; there is no Matrix dive

There is no jacking in, no second map, no IC grid. The Decker is a fighter-technomancer: they Scan to reveal devices on the physical Site, then hack guns, optics, doors, lights, locks, commlinks, and drones from where they stand, with effects that resolve immediately in the same encounter. The Decker's Drain cost scales with device rating.

**Considered options**: a separate procedural dive map with deck-versus-IC combat (rejected: it requires a second generator, a second renderer mode, and a second combat system — the single most expensive subsystem available, and it would strand the other three Runners while the Decker plays a different game); Marks and Overwatch on in-world devices (rejected as more state than the effect is worth); an abstract check suite in a panel (rejected: the class becomes a minigame); cutting the class entirely (rejected once the device-hacking model made it cheap).

**Consequences**: the device layer is a *content* burden rather than a systems burden — every hackable object type needs a defined effect, and Sites must place devices deliberately. Two classes now apply area and space effects (Shaman and Decker) and two cast damage (Mage and Decker), so the class kits must be cross-checked against each other when new abilities are written.
